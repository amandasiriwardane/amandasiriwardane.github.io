SSF/CAEP Event Delivery for WSO2 Identity Server

Designed and built a connector implementing the SSF Stream Management REST API, so WSO2 Identity Server can deliver CAEP security events to external receivers over an OAuth2-protected, standards-based transport. The service layer delegates CRUD to the existing WebhookManagementService to avoid duplicated persistence logic. Redesigned event-publisher resolution from a single, non-deterministic lookup to a per-event-profile map, so the new JWS-signing SSF publisher runs alongside the existing HTTP publisher with zero regression.
